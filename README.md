# XXIDLUA — Exhibition

Portfolio site of 서예준 (XXIDLUA). Specimen 001: *Color Image*, a bifold leaflet with a folded business card.

Static site, no build step: open `index.html` through any web server.

- `main.js` — intro: typewriter, lights, 3D velvet curtain, the frame and the shredder
- `story.js` — everything after the shred: 3D paper strips, particle dissolves, the leaflet and card (one-sheet folds), roses, captions, sound cues
- `sounds.js` — sound effects (base64); `music.mp3` — Erik Satie, Gymnopédie No. 1 (CC0 recording, Wikimedia Commons)
- Images: leaflet / card artwork rendered from the original print PDFs
